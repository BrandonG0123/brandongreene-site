Set up this site so the independent study has somewhere to be documented as it
happens, rather than written up from memory at the end.

Decisions worth recording: it's a static Astro build with hand-written CSS and
self-hosted fonts, and every project carries a status — Shipped, In progress or
Planned — that is shown rather than implied. Planned work gets one line and no
page, deliberately. Colour contrast for both themes was computed against WCAG
2.2 AA rather than eyeballed; two of the ten pairs failed the first check and
were changed.
