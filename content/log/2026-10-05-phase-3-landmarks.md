Built Phase 3: a viewer for the 3D model where you pick landmarks on the foot.
Picks snap to the stickers placed on the foot before scanning, and the
measurements are saved with them, so the same foot can be measured the same way
every time.

Built with Claude Code, which wrote most of the code while I directed it.
