Started Phase 4: a generator that turns a foot scan into a first-fit insole, saved
as a 3MF file a 3D-printer slicer can open. In the studio it's one button, "Make
insole", on a scan.

This is a first fit, not something to wear yet. Anything worn for sport has to be
signed off by a clinician first; that rule is part of the project, not an
afterthought.

Built with Claude Code, which wrote most of the code while I directed it.
