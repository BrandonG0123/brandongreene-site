Object scan: not measurable. Without the mat there's no real-world scale, so this capture tests the camera, quality checks and upload only. It is never used for foot measurements.

Before you start

Scan mat required for every foot condition: frames are only kept while at least two mat markers are in view, so each saved photo can be scaled to millimetres. Print the scan mat. Choose Object above to test the scanner without one.

On your phone: run footscan serve --host 0.0.0.0 --https and open the private studio address it prints.
